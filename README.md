## Бібліотеки

1. **[Glide](https://github.com/bumptech/glide)** 
   * **Призначення:** Асинхронне завантаження зображень з мережі. Використовується для швидкого рендерингу постера фільму у високій якості.
2. **[KenBurnsView](https://github.com/flavioarfaria/KenBurnsView)** 
   * **Призначення:** Анімація фону. Додає ефект плавного масштабування та панорамування до статичного постера, "оживляючи" екран.
3. **[Shimmer for Android](https://github.com/facebook/shimmer-android)** (від Facebook)
   * **Призначення:** Індикація завантаження. Текст опису фільму має красивий ефект металевого відблиску, доки користувач не пройде онбординг.
4. **[TapTargetView](https://github.com/KeepSafe/TapTargetView)**
   * **Призначення:** Онбординг. Надає візуальну підказку у вигляді Material-кола, яка фокусує увагу користувача на головній кнопці "Придбати квиток".
5. **[Konfetti](https://github.com/DanielMartinus/Konfetti)** 
   * **Призначення:** Ефекти. Використовує високопродуктивну систему частинок для генерації святкового конфетті під час успішного "бронювання".
